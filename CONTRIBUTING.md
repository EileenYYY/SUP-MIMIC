# Contributing

## Workflow

1. Update the documentation in `docs/`.
2. Keep each SQL file focused on one extraction topic.
3. Keep Python code testable and deterministic.
4. Add a minimal test for every new screening rule.
5. Do not add raw MIMIC data to the repository.

## Code Style

- Python 3.10+
- type annotations preferred
- parameterized SQL
- stable output formats and field names
