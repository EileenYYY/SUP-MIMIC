# Open Source Scope

本项目的原则很简单：

- 开源代码
- 开源 SQL 模板
- 开源配置样例
- 开源操作手册
- 开源统计与建模脚手架
- 不开源原始 MIMIC 数据

## 可以开源的内容

1. 数据抽取脚本
2. 特征工程代码
3. 筛选规则
4. 统计分析代码
5. 机器学习训练和评估代码
6. 文档、教程、示例配置
7. 单元测试和 synthetic example

## 不能直接开源的内容

1. 原始 MIMIC 表数据
2. 未经许可分发的受限派生数据
3. 含有可识别信息的任何导出
4. 受授权限制的第三方模型权重或数据

## 推荐发布方式

- 代码仓库只放方法，不放真实患者数据
- 提供 SQL 模板和字段映射
- 提供 synthetic case profile 作为演示
- 用户自己在本地 MIMIC 环境中运行提取
