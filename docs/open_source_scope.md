# Open Source Scope

The repository releases methods, code, and public-facing documentation.

## Public Contents

1. Data extraction scripts
2. Feature engineering code
3. Screening rules
4. Statistical analysis code
5. Machine-learning training and evaluation code
6. Documentation, tutorials, and example configs
7. Unit tests and synthetic examples

## Restricted Contents

1. Raw MIMIC tables
2. Restricted derived patient-level data
3. Any export containing identifiable information
4. Third-party model weights or data that are restricted by license

## Release Form

The public GitHub repository contains code and documentation only. Real patient data stay inside the authorized local MIMIC environment.
