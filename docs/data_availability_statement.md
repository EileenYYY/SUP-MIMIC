# Data Availability Statement

The code, SQL templates, configuration templates, and synthetic examples needed to reproduce the SUP-MIMIC workflow are available in this repository. The repository does not contain raw MIMIC data, patient-level derived data, or restricted model input/output logs.

The MIMIC-IV data used in the study are available from PhysioNet subject to credentialing, completion of the required training, and acceptance of the applicable data-use agreement. Researchers with authorized access can recreate the benchmark locally by running the released SQL and Python pipeline against their own MIMIC installation.

Patient-level artifacts generated during reproduction are handled according to the PhysioNet Credentialed Health Data License, institutional approval, and local data-governance requirements.
